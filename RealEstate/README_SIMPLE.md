# 🏠 Real Estate Website - Simple Guide

## 👋 Welcome!

This is your real estate website with an admin panel to manage properties.

---

## 🚀 Getting Started (First Time Only)

### 1. Install Required Software

**You only need to do this once!**

1. **Install Python:**
   - Go to: https://www.python.org/downloads/
   - Click "Download Python"
   - When installing, check ✅ "Add Python to PATH"
   - Click "Install Now"

2. **Install Node.js:**
   - Go to: https://nodejs.org/
   - Click "Download" (LTS version)
   - Run the installer
   - Click "Next" through all steps

3. **Restart your computer** after installing both

### 2. Run First-Time Setup

1. **Double-click:** `SETUP_FIRST_TIME.bat`
2. Wait for it to finish (5-10 minutes)
3. When it says "Setup Complete!", you're ready!

---

## 🎯 Daily Use (How to Start Your Website)

### Every time you want to use the website:

1. **Double-click:** `START_BACKEND.bat`
   - Wait until you see "Application startup complete"
   - **Keep this window open!**

2. **Double-click:** `START_FRONTEND.bat`
   - Wait until you see "Local: http://localhost:5173"
   - **Keep this window open too!**

3. **Open your browser** and go to: **http://localhost:5173**

That's it! Your website is running! 🎉

---

## 🔐 Admin Panel

To manage properties:

1. Go to: **http://localhost:5173/admin/login**
2. Login with:
   - Username: `admin`
   - Password: `admin123`
3. You can now add, edit, and delete properties!

---

## 🛑 How to Stop

Just close both black windows (backend and frontend).

---

## 📁 Important Files

- `START_BACKEND.bat` - Starts the server
- `START_FRONTEND.bat` - Starts the website
- `SETUP_FIRST_TIME.bat` - First-time setup (run once)
- `STOP_ALL.bat` - Stops everything

---

## ❓ Common Questions

**Q: Do I need to run setup every time?**  
A: No! Only the first time.

**Q: Can I close the black windows?**  
A: No! They keep your website running. Close them only when you're done.

**Q: What if something doesn't work?**  
A: Check the black windows for error messages. Make sure Python and Node.js are installed.

**Q: How do I change the admin password?**  
A: Edit `backend\.env` file and change `ADMIN_PASSWORD=your-new-password`
